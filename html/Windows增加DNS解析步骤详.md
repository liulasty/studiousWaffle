在 Windows 系统中增加 DNS 解析记录可以通过修改本地 Hosts 文件或配置网络接口的 DNS 服务器来实现。以下是详细步骤：

---

### **方法 1：修改 Hosts 文件（本地 DNS 解析）**
**适用场景**：手动指定特定域名的 IP 地址，优先级高于公共 DNS 查询。

1. **以管理员身份打开记事本**  
   - 按下 `Win + S`，输入 **记事本**。
   - 右键点击“记事本”，选择 **以管理员身份运行**。

2. **打开 Hosts 文件**  
   - 在记事本中点击 **文件 > 打开**，导航到以下路径：  
     ```
     C:\Windows\System32\drivers\etc
     ```
   - 将文件类型改为 **所有文件 (*.*)**，选择 **hosts** 文件并打开。

3. **添加 DNS 解析记录**  
   - 在文件末尾按格式添加记录（每行一条）：  
     ```
     IP地址 域名
     ```
     例如：  
     ```
     192.168.1.100 example.com
     ```

4. **保存文件**  
   - 按 `Ctrl + S` 保存，如果提示权限问题，需确保以管理员身份操作。

5. **刷新 DNS 缓存**  
   - 打开命令提示符（管理员权限），运行：  
     ```
     ipconfig /flushdns
     ```

---

### **方法 2：更改网络接口的 DNS 服务器**
**适用场景**：更换全局 DNS 服务器（如使用 Google DNS、Cloudflare DNS 等）。

6. **打开网络设置**  
   - 右键点击任务栏网络图标，选择 **“打开网络和 Internet 设置”**。
   - 进入 **“更改适配器选项”**。

7. **修改网络接口配置**  
   - 右键当前使用的网络（如以太网/Wi-Fi），选择 **属性**。
   - 双击 **“Internet 协议版本 4 (TCP/IPv 4)”**。

8. **设置自定义 DNS**  
   - 选择 **“使用以下 DNS 服务器地址”**，输入首选和备用 DNS：  
     ```
     首选：8.8.8.8（Google DNS）
     备用：1.1.1.1（Cloudflare DNS）
     ```
   - 勾选 **“退出时验证设置”**，点击 **确定**。

9. **应用更改**  
   - 重启网络连接或运行命令刷新 DNS：  
     ```
     ipconfig /flushdns
     ```

---

### **验证 DNS 解析是否生效**
- **方法 1**：使用 `ping 域名` 检查是否解析到指定 IP。
- **方法 2**：用 `nslookup 域名` 查看使用的 DNS 服务器和返回结果。

---

### **注意事项**
- **Hosts 文件**：仅影响当前设备，需管理员权限编辑。
- **公共 DNS**：修改后影响所有域名解析，可能需重启生效。
- **企业网络**：若域名由内网 DNS 服务器管理，需联系网络管理员。

根据需求选择合适的方法即可。
